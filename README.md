# Speaking in Tokens

Speaking in Tokens turns an engineering request and its codebase into one reviewable `spt_<task>.md` artifact with a descriptive task name.

The artifact starts with a plain-English system diagram, explains the motivation and proposed behavior, makes constraints and invariants explicit, maps the design to concrete code, and builds toward a complete granular system view. Concrete test coverage follows the complete design, informed by fault research but expressed directly as test cases, observables, properties, and oracles.

The skill produces the plan only. It does not create alternate drafts, process reports, approval stages, implementation handoffs, or standalone current-system and testing-research sections.

See [SKILL.md](SKILL.md) for the full workflow and artifact requirements.
